## COMM-001 callback authentication

*Callback authentication (COMM-001, ct scope-review-66 approved 21 October 2026):* authentication precedes delivery-payload parsing, message lookup, database writes and outbound effects. SNS necessarily decodes its bounded signed envelope and fetches only its pinned certificate to verify the signature; its SES Message remains unparsed until verification. Disconnected email returns 404. Every failed authentication/schema/recipient check returns the same generic 401 body, writes no Activity, durable counter, receipt/event ID or other business record, and logs only a generic Worker warning without secrets. After 20 rejections from one IP in a minute, further rejected requests return 429; verified traffic is never counted or refused by that rejection allowance. Authenticated events for messages Glove did not send through that provider return the same opaque 200 acknowledgement as matched events, with no effect and no consumed event ID; a wrong recipient for a known message refuses the entire batch. The owner's email settings show the last verified matched event time and any SNS cancellation warning. Unauthenticated and unmatched events never change delivery state, bounce/spam warnings, suppression/opt-outs, subscriptions or inbound email, request, conversation or customer records; never write Activity/export or reveal message/customer/recipient existence. Every future inbound-email receiver inherits this authentication before shipping.

Postmark: HTTPS Basic user `glove`, with a per-installation password generated from 32 random bytes and shown only in the first owner response. Store only its SHA-256 hash and compare in constant time. `mail.callback {action: rotate}` keeps the previous hash valid for exactly 24 hours (exclusive expiry), `revokePrevious` ends that overlap immediately, and disconnect revokes both. Rotation, revocation and allowlist changes are Activity facts without secrets. The optional source-IP allowlist is off by default, pinned in source with a dated provider reference, fails closed when on and never replaces Basic authentication; reconnecting credentials preserves this owner option unless explicitly changed. Plain-HTTP Postmark callbacks are refused without writes. Replay identity is event type plus Postmark ID, or message ID + type + recipient + time when no ID exists; refuse events over 7 days old. Sends include Glove's delivery ID in Postmark metadata. Delivery maps to delivered, hard bounce to bounced, soft bounce to deferred or failed when final, and SpamComplaint to complained.

Amazon SES via SNS: pin region, TopicArn and configuration set to the owner's connection. Require the message-type header to equal the envelope Type, accept SNS signature versions 1 and 2 (setup asks for version 2), and require the signing certificate at `https://sns.<region>.amazonaws.com/SimpleNotificationService-*.pem` with no query, credentials, fragment, alternate port or redirects; cache the certificate within its validity for at most one hour. SNS timestamps are at most 1 hour old and at most 5 minutes ahead. Require a signed SNS envelope (raw delivery off), the pinned SES configuration set and Glove delivery tag on each SES event; sends carry the configuration set and a base64url-encoded delivery ID tag. Deduplicate SNS MessageId and the SES event. A SubscriptionConfirmation URL is fetched only after all source, URL, timestamp and signature checks; require HTTPS on the same pinned regional SNS host with the exact ConfirmSubscription action, TopicArn and Token, and follow no redirects. An UnsubscribeConfirmation warns the owner and never fetches its URL. Delivery maps to delivered; Permanent bounce to bounced; Transient bounce to failed; DeliveryDelay to deferred; Complaint to complained; Reject and RenderingFailure (including AWS's `Rendering Failure` spelling) to rejected. SendGrid and Resend retain their signatures, with the same shared no-effect unmatched rule. Callback credentials, hashes and AWS/API keys are excluded from exports and archives, and restored email must be reconnected.
